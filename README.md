# atlas-prototipo-web
Prototipo web interactivo de Project ATLAS, un Portal del Colaborador gamificado en Unity. Incluye 15 estaciones funcionales (solicitudes, nómina, documentos, encuestas, muro y más), NPCs de IA con chat simulado, accesibilidad completa y configurabilidad de marca por empresa. Equipo: Top-Down Studios.
